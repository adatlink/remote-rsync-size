# Changelog

## 1.0.0 — 2026-10-17

- First packaged GitHub release.
- Multiple remote directories in a single CLI invocation.
- JSON output with per-directory and aggregate size, regular-file and directory counts.
- Per-directory and overall elapsed times.
- SSH key/agent and optional password/passphrase authentication.
- SSH tunnel support via host/port parameters.
- Explicit failure reporting and exit status.
- Unit and CLI smoke tests, automated GitHub Actions CI.
